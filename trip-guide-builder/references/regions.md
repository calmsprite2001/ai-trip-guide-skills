# 全国地域适配指南

**本 skill 的目标是「全国任意目的地的旅行攻略」。** 这份文件解决一件事：同一个模板，怎么适配不同地域。

## 一、适用范围

| 区域 | 适用情况 |
|---|---|
| **中国内地各省市区** | ✅ 全流程适用（12306 + 身份证实名 + 高德导航 + 国内景区预约体系） |
| **中国香港 / 中国澳门** | ⚠️ 主流程可用，需额外补：港澳通行证及签注、当地交通卡（八达通/澳门通）、部分场馆的独立预约系统 |
| **中国台湾** | ⚠️ 主流程可用，需额外补：大陆居民往来台湾通行证及签注、入台证、当地交通（台铁/高铁/悠游卡） |
| 出境 | ❌ 不在本 skill 范围（需另配签证、汇率、境外支付、国际漫游模块） |

内地部分是主力场景，下面的地域类型全部针对内地。

## 二、地域类型 → 配色 + 配图元素

选配色看**线路气质**，不看行政区域。一个行程跨多类型时，取**占比最大的那种**。

| 地域类型 | 典型目的地 | 推荐配色 | 封面长卷的地标元素 |
|---|---|---|---|
| **草原 / 沙漠 / 戈壁** | 内蒙古、新疆、甘肃、宁夏、青海 | **A 奶油暖调** | 草原、蒙古包、沙丘曲线、驼队、烽燧、雅丹 |
| **雪山 / 高原湖泊** | 西藏、青海、川西、滇西北 | **D 靛青海港** 或 **B 清透冷调** | 雪峰、经幡、圣湖、牦牛、玛尼堆 |
| **江南水乡 / 古镇** | 苏杭、皖南、湘西、丽江 | **C 墨绿山野** 或 **B 清透冷调** | 白墙黛瓦、拱桥、乌篷船、竹林、梯田 |
| **海岛 / 海滨** | 海南、厦门、青岛、舟山、北海 | **B 清透冷调** | 海浪、渔船、灯塔、椰林、礁石 |
| **都市 / 现代** | 北上广深、成渝、武汉、长沙 | **D 靛青海港** | 天际线、地标塔、跨江大桥、地铁、江景 |
| **森林 / 山野** | 东北、云南、福建、贵州 | **C 墨绿山野** | 林海、瀑布、苔藓、木屋、溪流 |
| **古都 / 中原历史** | 西安、洛阳、开封、北京、大同 | **A 奶油暖调** | 城墙、宫殿、佛塔、石窟、古街 |
| **喀斯特 / 峰林** | 桂林、黔东南、张家界 | **C 墨绿山野** | 峰林、溶洞、竹筏、吊脚楼、云海 |

配色详情（完整 CSS 变量）→ `palettes.md`

**图底色必须与所选配色的 `--paper` 同色系**，这条不分地域。

## 三、交通方式（按地域差异）

| 方式 | 适用地域 | 要点 |
|---|---|---|
| **飞机** | 全国 | 支线机场（稻城、九寨、阿勒泰、敦煌、喀什）航班少、常一票难求，**早订**；红眼航班落地到入住还要 1 小时 |
| **高铁 / 普速** | 全国 | 12306，预售期 15 天 → `ticketing.md` |
| **包车 / 拼车** | 新疆、西藏、青海、内蒙、川西、云南大环线 | **这是主力交通，不是备选**。按天计价（旺季 700–1500/天），要写进费用表 |
| **自驾租车** | 全国（大环线尤甚） | 注意异地还车费、驾照、保险、限行城市 |
| **景区索道 / 观光车 / 摆渡船** | 全国山区、湖区 | 常为**必选**（景区内禁私家车），含在票里或另购，要标清 |
| **城市地铁 / 公交** | 一二线城市 | 首末班时间，夜间到站要预留打车 |
| **轮渡 / 索道过江** | 重庆、武汉、沿海岛屿 | 部分需单独购票 |

**关键差异**：西北/西南大环线以「包车 + 铁路」为主，东部沿海以「高铁 + 地铁」为主。写交通段时先判断属哪一类。

## 四、特殊证件与准入（做攻略必须逐项确认）

| 项目 | 适用 | 说明 |
|---|---|---|
| **身份证原件** | 全国 | 火车、飞机、几乎所有景区都要**刷证 + 人脸**，电子身份证/截图不稳妥 |
| **边防证** | 西藏、新疆部分边境县 | 珠峰、阿里、塔县、白哈巴等需要；户籍地或目的地办理 |
| **高原健康提示** | 西藏、青海、川西、滇西北 | 行程留适应期，**首日不排满**，标注海拔、医疗点、氧气 |
| **儿童证件** | 全国 | 户口本或身份证；景区实名核验要用 |
| **老年证 / 学生证** | 全国 | 多数景区半价，需现场核验原件 |
| **港澳台居民来往内地通行证** | 内地 | 部分场馆另有预约通道 |

⚠️ **边境地区、无人区、自然保护区**（可可西里、羌塘等）另有准入规定，涉及的话必须单列说明。

## 五、季节性（决定"能不能去"和"怎么订"）

| 现象 | 影响 |
|---|---|
| **旺季限流** | 热门景区（故宫、九寨沟、莫高窟、张家界、黄山）**必须提前抢预约**，窗口从 2 天到 30 天不等 |
| **淡季闭园** | 部分景区冬季关闭、索道停运、班车停驶 —— 冬季线路必须逐项核实 |
| **天象窗口** | 额济纳胡杨林（10 月上旬）、川西红叶（10 月下旬）、青海湖油菜花（7 月）、雪乡（12–2 月）—— **错过就没了**，要写进行程逻辑 |
| **雨季 / 台风季** | 华南 5–9 月、西南雨季，可能封路断航，备选方案要写 |
| **黄金周** | 客流最高峰，票价与住宿翻倍、预约秒光，行程要留冗余 |

## 六、全国通用的坑（不分地域）

1. **旧攻略的票价和预约规则八成过期** —— 一律查当日官方公告。
2. **"XX站"不等于"XX东站"** —— 同城多站发车时刻不同，写全称。
3. **景区大门 ≠ 核心景点** —— 很多景区要先坐摆渡车/索道 30–60 分钟，时间要算进去。
4. **闭馆日** —— 绝大多数博物馆**周一闭馆**（法定节假日除外），排行程先用它当约束。
5. **高原首日别排满** —— 落地当天只安排轻度活动。
6. **大环线单日车程别超 5 小时** —— 超过就要拆成两天，否则全程都在赶路。
7. **包车要提前订** —— 旺季（暑期、国庆、春节）当地车源紧张，临时找车价格翻倍。
8. **老店只收现金** —— 小城老字号仍常见，备少量零钱。
9. **网络信号** —— 戈壁、沙漠、深山、边境路段常无信号，**离线版攻略在这里是刚需**（见 SKILL.md ⑦d）。

## 七、适配自查清单

定稿前逐条过：

- [ ] 配色是否匹配线路主要气质（不是随手选的）
- [ ] 交通段落是否用对了主力方式（大环线写了包车吗？城市线写了地铁吗？）
- [ ] 是否涉及边防证 / 高原 / 特殊准入 → 有没有单列说明
- [ ] 是否落在旺季 / 闭馆日 / 天象窗口 → 有没有写进决策逻辑
- [ ] 景区"大门到核心景点"的耗时是否算进行程
- [ ] 单日车程/步行量是否合理（有没有"全天赶路"的硬伤）
- [ ] 无信号路段是否提醒用离线版
