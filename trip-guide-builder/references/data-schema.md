# 数据结构 · 模板的 5 个数据块

模板 `assets/template.html` 把**全部内容**收在 5 个数据块里。**只改数据，别动渲染函数。**

文件很长，用编辑器按块定位即可（每块都有 `/* ==== 注释 ==== */` 分隔）。

---

## 1. `CFG` · 全局配置

```js
var CFG = {
  title:   '青甘蒙大环线 · 旅行攻略',   // 页面标题（总览页 hero 用）
  brand:   '青甘蒙大环线',              // 顶栏左侧短名，≤ 6 字最好
  heroImg: 'img/final/loop.jpg',       // 总览页 / 非城市页的封面
  heroAlt: '环线全景',
  kick:    '9/26 — 10/7 · 12 天',       // hero 上方小字
  sub:     '呼和浩特 → 银川 → 兰州 → 敦煌 → 张掖 → 兰州',   // hero 副标题
  t0: [2026, 8, 26],                   // 出发日 [年, 月-1, 日]  ← 注意月份从 0 开始
  t1: [2026, 9, 8],                    // 结束日次日 0 点
  totalDays: 12,                        // 行程总天数（倒计时显示 D3/12）
  foot: '...',                          // 页脚（可含 <br>）
  dayMap: { '9/27':'hohhot', ... }      // 'M/D' -> 城市 id，用于当天自动定位
};
```

`dayMap` 要覆盖**行程中的每一天**（含飞机上/火车上那几天，可映射到当天所在城市）。

## 2. `PLANE` / `TRAIN` / `BOOK` · 票务

```js
var PLANE = [
  { no:'EU1887', d:'9/26 21:50', from:'成都天府T2', to:'呼和浩特白塔',
    who:'1 人', note:'红眼航班，凌晨 1 点才能到酒店。' }
];

var TRAIN = [
  { no:'D1175', d:'9/29 08:28', from:'呼和浩特东', to:'银川 12:07',
    who:'1 人', sale:'9/15 14:00 开售', st:'未开售',
    note:'当天最快班次。备选 D3523（07:07→11:20）。' }
];

var BOOK = [
  { name:'鸣沙山月牙泉', at:'10/4 傍晚场', open:'9/19 起可购', st:'未预约',
    who:'1 大 1 小', note:'无现场票，只有线上实名预约，必须选 16:00–19:30 看日落。' }
];
```

| 字段 | 说明 |
|---|---|
| `no` | 航班号 / 车次（`BOOK` 里用 `name`） |
| `d` | 日期 + 时刻，如 `9/29 08:28`；跨日用 `次日 06:35` |
| `from` / `to` | **写全称**（含航站楼 / 东站 / 西站），跨日到达把时刻写在 `to` 里 |
| `who` | 乘客结构，会随行程变化，逐段写清 |
| `sale` | **开售时间**。火车票按预售期推算或用户告知；机票写 `—` |
| `st` | 状态：`已出票`/`已挂候补`/`未开售`/`未预约`/`直接入馆` |
| `note` | 备选班次、票价、抢票要点 |

**`st` 决定标签颜色**：`已挂候补` → sky 蓝；`直接入馆` → olive 绿；其余默认 mustard。

## 3. `CITIES` · 城市分册（主体）

```js
var CITIES = [
{
  id:'hohhot', name:'呼和浩特', img:'img/final/hohhot-v3.jpg',
  period:'9/27 — 9/29', nights:'住 2 晚', kw:'烧麦 · 火山 · 召庙群 · 博物院',
  days:[ ... ], eat:[ ... ], buy:[ ... ], walk:{ ... }, shots:[ ... ]
},
...
];
```

### 3.1 `days[]` 逐日行程

```js
{ date:'9/27', w:'周日', title:'凌晨落地 · 博物院 + 召庙群',
  tag:'硬撑的一天', tagCls:'red',
  sub:'00:10 落地 → 约 01:00 入住，睡 6–7 小时。',
  items:[
    { t:'08:20', x:'酒店出发。早餐就近解决或路上买个 <b>焙子</b>。' },
    { t:'09:00', x:'<b>内蒙古博物院</b>（赛罕区新华东街 76 号）…', warn:true }
  ],
  note:'从凌晨 1 点睡到 8 点，博物院上午场是最紧的一环。'
}
```

| 字段 | 说明 |
|---|---|
| `date` / `w` | `9/27` / 星期。`date` 会与当天比对，**命中则整卡高亮** |
| `title` / `sub` | 当日主标题 / 一句话概括 |
| `tag` / `tagCls` | 标签文字 / 颜色类（`red` `green` `sky` `paper`，空则 mustard） |
| `items[].t` | 时刻（左列，自动染红加粗） |
| `items[].x` | 正文，**可含 HTML**（`<b>` 强调） |
| `items[].warn` | `true` 则整条加浅红底 —— 用于"容易踩坑"的提示 |
| `note` | 底部小结。**写"为什么这么排"**，不是重复行程 |

`tag` 的用法：`硬撑的一天` / `全天户外` / `赶路日` / `本程重点` / `轻松半天`。

### 3.2 `eat[]` 吃

```js
{ name:'德顺源·非遗烧麦（大盛魁店）', star:true, sub:'烧麦百年号 · 人均 65',
  addr:'玉泉区大南街 席力图召东侧 大盛魁商业街南口',
  tel:'0471-2530311', hours:'06:00–21:00',
  dish:'羊肉大葱烧麦、砖茶熬奶茶',
  note:'一两约 8 个，按「皮」计两。' }
```
`star:true` 会显示推荐星标。**`addr` 必须写到门牌或建筑的哪一侧**，`tel` 让页面能一键拨号。

### 3.3 `buy[]` 买

```js
{ n:'牛肉干', w:'塞上老街 / 宽巷子 / 超市', p:'60–120 元/斤', t:'选真空小包装，能带上飞机' }
```
`n` 名称 / `w` 在哪买 / `p` 价位 / `t` 挑选要点。

### 3.4 `walk{}` citywalk 步行线

```js
walk:{
  name:'玉泉区老城召庙步行线',
  from:'大召寺', to:'宝尔汗佛塔',
  dist:'约 2.5 km', mins:'步行 40 分钟（不含参观）',
  stops:['大召寺 14:00','席力图召 15:00','五塔寺 15:45（17:00 关门）'],
  best:'16:30–18:00 老街光线最柔；20:00 后大召广场夜景',
  tip:'顺序别乱：五塔寺 17:00 关门，务必 16:00 前到。'
}
```
`stops` 带时刻，页面会渲染成有序节点。

### 3.5 `shots[]` 拍照打卡 · 机位

```js
{ s:'大召寺红墙', nav:'大召寺', at:'上午顺光',
  t:'上午顺光最浓，红墙配金顶。10 点后旅游团就上来了。' }
```

| 字段 | 说明 |
|---|---|
| `s` | 机位名（**能在地图上搜到**的名字） |
| `t` | 怎么拍 + 怎么去 + 人流 —— 具体到能照做，别写"很美" |
| `at` | **最佳时段**，渲染成蓝色小标签（`日落前 40 分` / `19:00 前后`） |
| `nav` | **导航关键词**（可省，省则用 `s`）。每条自动生成「导航去这里」按钮跳高德 |

**每城 5–8 个，覆盖 2–3 类**（全景 / 地标 / 夜景 / 街拍），按行程顺序排。
方法论与避坑 → `checkpoints.md`

## 4. `OV` · 总览页 / 票夹页 / 应急页内容

```js
var OV = {
  days:      [[日期, 安排, 住], ...],        // 总览「N 天全景」表
  weather:   [[地点, 白天, 夜间, 要点], ...],  // 天气表
  pack:      ['必带项', ...],                // 必带清单
  costRows:  [[项目, 前段, 后段], ...],       // 费用表

  doneExtra: [{title, tag, kv, note}],       // 票夹：已出票但非机票的项
  pickSteps:   ['抢票步骤', ...],             // 票夹：开售当天四步
  pickWindows: ['捡漏时机', ...],             // 票夹：捡漏窗口
  hardTips:    ['硬提醒', ...],               // 票夹：三条硬提醒
  stations:    [[车站, 起售时刻], ...],        // 票夹：各站起售时间

  emPhones: [[用途, 号码], ...],              // 应急电话（号码列写文字则不生成 tel: 链接）
  traps:    [{red:true, b:'粗体前半', x:'后半'}, ...],   // 防坑清单
  src:      ['核验说明行（可含 HTML）', ...]    // 底部来源与核验状态
};
```

⚠️ 两个易错点：
- `OV.days` 的**天数必须与 `CFG.totalDays` 对得上**，也要覆盖"飞机上/火车上"的日子。
- `OV.src` 是**信誉所在**，逐条写清依据与核验日期，核过的标 `<span class="flag ok">已核验</span>`。

## 5. `PAGES` · 页面注册

```js
var PAGES = [
  { id:'overview', name:'总览',     render: overviewPage },
  { id:'hohhot',   name:'呼和浩特', render: function(){ return cityPage(CITIES[0]); } },
  ...
  { id:'wallet',   name:'票夹',     render: walletPage },
  { id:'help',     name:'应急',     render: emergencyPage }
];
```

- **`id` 必须与 `CITIES[].id` 一致** —— `show()` 靠它找城市来切封面。
- `scaffold.py` 会按 `--cities N` 自动生成这一段，通常不用手改。
- 城市顺序 = Tab 顺序 = 行程顺序。

---

## 三条渲染约定

1. **顶部封面随城市切换**：`show(id)` 里遍历 `CITIES` 找同 id，命中则换 `heroImg.src / heroKick / heroTitle / heroSub`；未命中（总览/票夹/应急）回落 `CFG`。
   **这是最容易漏的功能** —— 漏了用户会反复反馈"每个城市的封面没变"。
2. **当天高亮 + 自动定位**：`isToday('9/27')` 比对 `new Date()`；`todayCityId()` 用 `CFG.dayMap` 决定首屏落在哪一页。
3. **倒计时**：`tick()` + `setInterval(tick,1000)`，出发前显示「距出发 N 天」，行程中显示「D3 / 12」，结束后显示"行程已结束"。
