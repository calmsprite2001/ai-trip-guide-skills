# 国内票务时间规则 + 抢票倒计时

> 规则会变。**核验日期 2026-09-13**，依据：国铁集团 2026 中秋国庆运输方案、12306 官方公告、《铁路旅客运输规程》。
> 使用前如距此日期较远，重新查一次再写进页面。

---

## 一、火车票（12306）

### 1. 预售期：15 天（含当日）

互联网售票与车站窗口**同为 15 天（含当日）**，实行**分地区错时售票**。

**开售日推算公式：**

```
开售日 = 乘车日 − 15 天 + 1 天

例：乘车日 9/29  →  开售日 9/15
    乘车日 10/1  →  开售日 9/17
    乘车日 10/5  →  开售日 9/21
```

用户知道开售时间就直接用（标注"用户提供"）；不知道就按公式推算，并在页面注明"以 12306 公告为准"。

### 2. 起售时刻：按【发站】而定

**同一趟车，从不同车站起售的时刻可能不同**，一定要按发站查：

> 12306 App → 我的 → 出行向导 → **起售时间** → 输入车站与日期

常见档位：`08:00 / 10:00 / 12:00 / 14:00 / 16:00 / 17:00` 等。页面里按「车站 → 起售时刻」列一张表，用户一眼能查。

⚠️ 12306 会发布《关于铁路车站起售时间的公告》，**以最新公告为准**。

### 3. 候补

- 放票没抢到 → **立刻挂候补**，别反复刷。
- 同一车次可**多选席别 + 相邻日期**。
- 每单上限：**3 个乘车日期、不超过 60 个车次**。
- 截止兑现时间**不晚于开车前 20 分钟**。
- 只在 12306 官方 App / 网站操作，**第三方加速包不提高成功率**。

### 4. 五个捡漏窗口

1. 开售 **30 分钟后** —— 未支付订单自动取消，票会回池
2. 开车前 **15 天** —— 此前退票免手续费，会有一波退票
3. 开车前 **48 小时** 与 **24 小时**
4. 每晚 **22:00–23:00**
5. **开车前一天**

### 5. 儿童票（按年龄，不是按身高）

| 年龄 | 规则 |
|---|---|
| 未满 6 周岁 | **免费**，每名持票成人可带 1 名（不单独占座）；超过 1 名，超出部分买儿童优惠票 |
| 年满 6 周岁、未满 14 周岁 | **儿童优惠票**（约半价） |
| 年满 14 周岁 | **全价票** |

- 年龄**按乘车日期**计算。
- 免费乘车儿童需在购票时**提前申明**，申明用的证件即乘车凭证。
- 免费儿童**单独占座**时须买儿童优惠票。
- 儿童票的日期、车次、席别须与同行成人一致，到站不得更远。

### 6. 改签

- 开车前 **48 小时以上**：可免费改签预售期内的列车。
- 开车前不足 48 小时：可免费改签到**乘车日期之前**的列车；改到**之后**要核收改签费。
- 开车后当日 24 时前：可免费改签当日其他列车。

### 7. 其他优惠

- **学生票**：每学年（10/1–次年 9/30）4 次单程，需资质核验。
- **老年票**：60 周岁及以上，可在预售期内**距开车前 3 天及以上**拨 12306 订票。
- **团体票**：12306 单笔上限 19 张，单账户乘车人上限 30 人。

## 二、机票

- **没有固定开售日**，一般提前 1–2 个月放出较优价格；廉航可能更晚。
- 儿童/婴儿票按航司规定（通常 2 岁以下婴儿票、2–12 岁儿童票），**需与成人同订单**。
- 红眼航班要额外提醒：**落地到入住通常还需 1 小时**，第二天行程不能排满。
- 页面里机票**不显示开售倒计时**（无可抢的固定时点），标"已出票"即可。

## 三、景区 / 博物馆预约

**没有统一规则，逐家查。** 常见窗口：

| 类型 | 典型提前量 | 放票时点 |
|---|---|---|
| 热门博物馆（省级） | 提前 3 天 | 每日固定点放票（如 09:00） |
| 部分博物院 | 提前 7 天 | 每日固定点放第 7 日名额 |
| 热门景区（莫高窟等） | 提前 10–30 天 | 提前放出，分时段 |
| 一般景区 | 提前 2–3 天 或 无需预约 | — |

**必查四项**：提前几天 / 每天几点放票 / 周几闭馆 / 是否已取消预约制。

> 真实踩坑：旧资料写"需分时预约"，实际官方已公告**取消预约，凭身份证直接检票入馆**。照抄旧资料会写出错误的行动指引。

预约渠道也要写清：小程序名 / 公众号名 / 官网。

## 四、抢票倒计时页实现

票多时单独做一个 `票务抢票倒计时.html`（模板可直接复用配色与卡片组件）。

### 数据结构

```js
var ITEMS = [
  { kind:'train', name:'D1175 呼和浩特东 → 银川', saleTime:'2026-09-15T14:00:00',
    target:'9/29 08:28 乘车', note:'当天最快班次' },
  { kind:'book',  name:'鸣沙山月牙泉', saleTime:'2026-09-19T09:00:00',
    target:'10/4 傍晚场', note:'无现场票' }
];
```

### 倒计时逻辑（三态）

```js
function tick(){
  var now = Date.now();
  ITEMS.forEach(function(it){
    var t = new Date(it.saleTime).getTime();
    var d = t - now;
    it.text = d > 0
      ? Math.floor(d/86400000) + ' 天 ' + Math.floor(d%86400000/3600000) + ' 小时'
        + Math.floor(d%3600000/60000) + ' 分'
      : '已开售';
    it.urgent = d > 0 && d < 2*86400000;     // 48 小时内高亮
  });
  render();
  setTimeout(tick, 1000);
}
```

- **按 `saleTime` 升序排**，最紧的排最前。
- 48 小时内用 `--red` 高亮（页面主色强调）。
- 已开售的项降饱和、置灰，一眼区分"要抢的"和"过去的"。

### 与主页的联动

主攻略的「票夹」Tab 顶部放一个按钮跳转到倒计时页；倒计时页底部返回。
两个页面共用同一份 `TRAIN` / `BOOK` 数据的**开售时间字段**，别两处各写一份（会不一致）。

## 五、追问话术（用户可主动告之）

> **哪些票还没买、需要抢？如果你已经知道开售时间（几号几点），直接告诉我，我写进抢票倒计时。不知道的话我按 12306 的 15 天预售期帮你推算，并在页面上标「以官方公告为准」。**

收到用户给的时间 → 写 `sale:'9/15 14:00 开售'`，来源标"用户提供"。
用户没给 → 按公式推算，来源标"按预售期推算"。

**两种来源都要在页面的「核验说明」里写清楚**，别混为一谈。

## 六、写进页面的模板句式

票夹 Tab 里给用户的动作指引（可直接复用）：

**开售当天四步**
1. 前一晚查 12306 App → 我的 → 出行向导 → 起售时间，确认发站当日放票时刻。
2. 开售当日先用「购票信息预填」填好乘车人、车次、席别，放票瞬间一键提交。
3. 放票后立刻提交候补：同一车次可多选席别和相邻日期，每单最多 3 个乘车日期、不超过 60 个车次。
4. 没抢到不要反复刷，直接挂候补，并在 12306 首页「设置提醒」订阅出发车站。

**三条硬提醒**
- 客流最高峰日（如国庆首日）的跨省干线最难，务必卡点抢。
- 候补单截止兑现时间不晚于开车前 20 分钟。
- 只走 12306 官方 App / 网站，第三方加速包不提高成功率。
