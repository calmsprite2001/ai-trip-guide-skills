## 最贵的一条：用户说"没变化"，别先怀疑缓存

**症状**：改完图重新发布，用户连续三轮反馈「线上还是旧图 / 每个城市的封面图没修改」，换了设备、换了浏览器都一样。

**当时怎么错的**：三轮全在查缓存 —— 下载线上文件算 md5、查响应头、零缓存无头渲染，**全部证明服务端是新图**。方向从头到尾是错的。

**真因**：`grep -n "c\.img" page.html` → **零结果**。
`CITIES[].img` 字段定义了，但**没有任何渲染函数读它**。页面顶部是一张写死的静态封面，切到任何城市都不换。所以那 5 张辛苦做的城市图，**页面上一次都没出现过**。用户说的字面上完全正确。

**正确排查顺序：**

1. `curl` 下载线上文件 + `md5sum` 比对本地 → 判断**服务端**新旧
2. 零缓存无头浏览器渲染线上页 → 判断**客户端缓存**
3. **`grep` 字段名 / 渲染函数 → 判断"这个数据到底有没有被用到"** ← 往往最快最致命
4. 都正常才考虑 CDN 边缘节点、中间代理

> **"服务端是新的" ≠ "用户能看到新的"。**

## 无头浏览器验证

| 症状 | 真因 | 解法 |
|---|---|---|
| 390px 下表格/图片右侧被切，以为 CSS 溢出 | **Windows 125% 缩放下 `--window-size=390` 实际渲染成 481px CSS 视口**，截图只存 390px | 改用 **iframe 外壳锁精确宽度**；`--force-device-scale-factor=1` **治不了**这个（仍 477） |
| 截图显示旧内容 | 同一路径复用 + Edge 实例冲突 | 换新文件名；加 `--user-data-dir=<独立目录>` |
| CDP 抓到的页是 `edge://` 而不是目标页 | 首次启动的**同步确认弹窗**抢走了 page target | 启动时给 `about:blank`，加 `--disable-sync --no-first-run --no-default-browser-check` |
| CDP 里 `typeof show === 'undefined'` | 同上（拿到的是弹窗页） | 同上 |

详见 skill `mobile-html-headless-verify`。

## 发布与缓存

| 症状 | 真因 | 解法 |
|---|---|---|
| 加了 `?v=2` 还是旧图 | 托管网关**忽略 query string** —— `x.jpg?v=2` 与 `x.jpg` 返回相同 `Content-Length`/`Last-Modified`，服务端不构成新资源 | **换文件名**：`x.jpg` → `x-v3.jpg`，批量替换引用（**三种引号形态都要覆盖**）；含连字符的新名要放宽内联脚本正则 |
| 网关无缓存头 | 实测无 `Cache-Control` / `ETag` / `Expires`，只有 `Last-Modified` | 浏览器走启发式缓存，只能靠换名绕开；顺手注入 `no-cache` meta（聊胜于无） |
| 用户端仍是旧入口 | 入口 HTML 被缓存 | 给一条**从未访问过的新路径**（如 `/guide.html`，内容相同） |
| 替换后仍有旧引用残留 | 引号形态不全 / 内联正则太窄 | 替换后自检 `grep`，残留数必须为 0 |

## 内容核实

| 症状 | 真因 | 解法 |
|---|---|---|
| 费用/住宿全篇作废 | 旧行程书按「2 大 1 小」写，实际「1 人 + 1 大 1 小」 | **追问阶段必须单独确认"人数是否中途变化"** |

## 本机环境（Windows）

| 症状 | 解法 |
|---|---|
| Bash 工具 `dirname: command not found` / `exit 127` | PATH 间歇性为空。命令前显式导出 PortableGit 路径（按实际安装位置改）：<br>`export PATH="/c/Program Files/Git/usr/bin:/c/Program Files/Git/mingw64/bin:/c/Windows/System32:/c/Windows"`<br>或**避免接管道**（`\| tail` 会放大问题），改为重定向到日志文件后用 Read 工具读 |
| PowerShell 完全无回显（连 `1+1` 都没有） | 改用 Bash + 显式 PATH，或把结果写文件再 Read |
| 中文路径传给 `node.exe` 出乱码 | 起 `python -m http.server` 用 `http://127.0.0.1:端口/` 的**纯 ASCII URL** 访问 |
| 调 Edge 时中文路径参数出错 | 一律用 Python `subprocess` 调，URI 用 `pathlib.Path.as_uri()` |

## 心法三条

1. **用户反馈"没变化"时，先证伪自己的假设，别顺着第一直觉往下钻。** 缓存是最容易想到的解释，也最容易判断错。
2. **凡是"定义了但没用上"的数据，都是定时炸弹。** 写完立即 grep 一次。
3. **能数值化的判断就别靠肉眼。** 溢出测 `scrollWidth`、图片加载测 `naturalWidth`、新旧测 `md5`，比看截图可靠得多。
