# 行程设计 · 选哪些景点，城市间怎么走

> 来源解决"数据真不真"，这份解决"行程对不对"。
> **景点不是查出来的，是设计出来的** —— 同一座城市，不同偏好会排出完全不同的行程。
> 这份文件给一套可复用的设计方法，任何目的地套进去都能跑。

---

## 零、总原则

**顺序：先钉锚点 → 再选点 → 后编排 → 末校验**

```
锚点（不可动的） → 城市主点（为什么来） → 候选分层 → 时长估算 → 日编排 → 交通串联 → 可行性校验
```

一次性排完必出问题。**每一步只解决一件事**，排完一层再进下一层。

---

# 第一部分 · 景点怎么选

## 1. 锚点识别（最先做）

行程里**已经钉死、不可移动**的东西，它们是骨架：

- 已出票的航班 / 车次（时刻固定）
- 固定场次的门票（如"莫高窟 12:15 场"）
- 接人 / 送人的时刻
- 必须赶上的返程

**全部先落到日历上**，形成"这一天这个时段被占了"的硬边界。后面的编排在缝隙里填。

## 2. 城市定位 —— 一句话说清"为什么来"

每个城市先写一句：**它最不可替代的是什么？**

| 城市 | 不可替代的 |
|---|---|
| 敦煌 | 莫高窟 + 鸣沙山月牙泉（丝路双绝） |
| 张掖 | 七彩丹霞 |
| 呼和浩特 | 召庙群 + 内蒙古博物院 |
| 兰州 | 黄河穿城（中山桥 + 水车园） |

**这句话决定主点。** 说不出这句话的城市，考虑是不是该砍掉 ——
多塞一个"路过城市"会挤掉真正值得的地方。

## 3. 候选分层（四层）

每个城市列 6–10 个候选，按下面分层：

| 层 | 数量 | 定义 | 处理 |
|---|---|---|---|
| **必去** | 1–2 | 不去等于没来 | 一定排进，优先占好时段 |
| **主题** | 2–4 | 符合用户偏好（历史 / 自然 / 美食 / 摄影 / 亲子） | 按偏好筛，宁缺勿滥 |
| **顺路** | 1–3 | 地理上就在主点旁边，零额外交通 | 顺手排，提升密度 |
| **机动** | 1–2 | 有时间才去 | **标"机动"，排行程时留作缓冲** |

⚠️ **给用户看候选时用清单形式让他挑**（用户习惯先看候选再定），
不要自己闷头决定，也不要问"你想去哪"这种开放问题 —— 用户答不上。

## 4. 时长估算（含隐性成本）

**每个点算三笔，不是一笔：**

```
真实耗时 = 游览时长 + 往返交通 + 排队/摆渡/索道
```

| 类型 | 游览 | 备注 |
|---|---|---|
| 省级博物馆 | 2–3 h | 只想看镇馆之宝可压到 1.5 h |
| 大型景区（含摆渡/索道） | 3–5 h | **门票只到大门，核心景点还在里面 30–60 min 车程** |
| 寺庙 / 单点建筑 | 1–1.5 h | — |
| 老街 / 夜市 | 1.5–2 h | 含吃饭 |
| 自然景观（日出/日落） | 2–3 h | 受天光时间约束，要卡点 |

🔴 **最容易漏的：景区大门 ≠ 核心景点。**
很多景区要先坐摆渡车 / 索道 30–60 分钟。这条漏了就必然赶路。

## 5. 日编排（五条规则）

1. **地理聚类**：同一片区 / 同一方向串成一天。**别一天来回穿城两次。**
2. **固定锚点先落位**：有预约场次的先钉进去，其余围着它排。
3. **一天 2–3 个主点，上限 4 个**（含顺路）。再多就是打卡不是旅行。
4. **留一顿正经饭的时间**。别把吃饭排成"路上买个焙子"。
5. **首末两日减半**：
   - 落地日（尤其红眼 / 高原）只排 1 个轻量点
   - 返程日只排"昨天附近的点"，留出到站/到机场的时间

**给每天的卡加一个标签**：`硬撑的一天` / `全天户外` / `赶路日` / `本程重点` / `轻松半天`
—— 用户一眼能看出今天累不累，这是好攻略的标志。

## 6. 天数校验

```
城市所需天数 ≈ ⌈（必去 + 主题的主点耗时合计）÷ 每天可用 6–7 h⌉ + 交通日
```

- **不够** → 依次砍：机动层 → 顺路层 → 主题层里最弱的
- **多了** → 加机动，或把顺路层升级
- **黄金周**：所有时长 ×1.3（排队、堵车、限流），别按淡季排

# 第二部分 · 城市间交通怎么走

## 1. 先判定走廊类型

| 类型 | 特征 | 主力方式 |
|---|---|---|
| **城市群走廊** | 长三角 / 珠三角 / 京津冀 / 成渝 | **高铁**，班次密，随到随走 |
| **长距离点对点** | 跨省远距离 | **飞机**（> 1500 km）/ 高铁（< 1200 km） |
| **大环线** | 新疆 / 西藏 / 青海 / 内蒙 / 川西 / 滇西北 | **包车 / 自驾**；铁路只连主干城市 |
| **单点放射** | 以一个城市为基地往返 | 城际 + 包车组合 |

🔴 **判错走廊 = 全盘错。** 西部大环线写成"高铁串联"是最典型的错误 ——
那里的主力是包车，按天计价（旺季 700–1500/天），**要进费用表**。

## 1.5 四种方式怎么选（按距离速查）

用户说"你帮我选"时，按这张表给方案：

| 距离 | 首选 | 备选 | 说明 |
|---|---|---|---|
| < 100 km | 🚌 **大巴 / 城际公交** | 🚄 城际铁路 | 班次密、直达；注意末班车早 |
| 100–300 km | 🚌 **大巴** 或 🚄 **高铁** | 🚗 拼车 | 有大巴直达景区门口就优先大巴；有高铁则高铁更稳 |
| 300–1200 km | 🚄 **高铁** | ✈️ 晚班机 | 高铁准点、站多在市区；夜间到可省一天 |
| > 1200 km | ✈️ **飞机** | 🚄 高铁 | 飞机两端各留 3 h；**支线机场班次少要早订** |
| 无铁路 / 景区分散 | 🚗 **包车 / 自驾** | 当地一日游直通车 | 西部环线的唯一可行解 |

**比较时永远算"门到门总时长"**，不是班次时长：
飞机要加「去机场 1 h + 安检候机 2 h + 落地到市区 1 h」= **两端约 4 h**；
火车站多在市区，两端各 0.5–1 h；大巴站可能更偏。

**大巴的三个坑**：班次少（一天可能就 2–3 班）、末班早（下午就收）、
受天气路况影响大（雨雪天停运，山区尤甚）。**坐大巴必须确认末班时间。**

## 2. 排序三原则

1. **不走回头路** —— 地理上连成线：A→B→C→D。别排成 A→C→B 再折回。
2. **班次可行性优先** —— 先查有没有合适的车，**再定顺序**。别排出理想路线却没有班次。
3. **总时间成本最小** —— 同一段别为省 50 块钱多花 4 小时。用户的时间比差价值钱。

## 3. 可行性校验（三条铁律，排完必查）

1. **到达日不排满。** 跨省 / 红眼 / 高原落地当天只排轻量项。
2. **单日车程 > 5 h 就拆成两天**，否则全程在赶路。
3. **末班车之后要有过夜方案。** 排出"晚上 22:00 到某小镇"却没确认住宿，是重大失误。

## 4. 换乘要点

| 事项 | 规则 |
|---|---|
| **同城多站** | 兰州站 ≠ 兰州西站，杭州东 ≠ 杭州。**页面写全称**，票面也要核对 |
| **换乘预留** | 同站 30 min+；异站 2 h+（含地铁进城时间） |
| **跨夜车** | 省一晚住宿，但要评估体力（软卧尚可，硬座影响次日状态） |
| **末段接驳** | 火车站/机场到酒店 30–60 min，红眼落地要加 1 h |
| **票务前置** | 火车 15 天预售期 → **倒推开售日**；支线航班（敦煌/稻城/阿勒泰）班次少，早订 |

票务时间规则 → `ticketing.md`

## 5. 每段交通都要给"备选"

主选 + **1 个备选班次**（晚 1–2 小时内的），写进 `TRAIN[].note`。
旺季票难抢，用户抢不到主选时不至于当场抓瞎。

# 第三部分 · 产出：行程骨架表

选点和交通收敛成一张表，**这是后续所有环节的依据**：

| 日期 | 城市 | 交通（班次 + 时刻） | 主点 | 宿 |
|---|---|---|---|---|
| 9/26 | 成都 → 呼和浩特 | EU1887 21:50→00:10 | — | 呼市 |
| 9/27 | 呼和浩特 | 市内 | 博物院 + 召庙群 | 呼市 |
| 9/29 | 呼市 → 银川 | D1175 08:28→12:07 | 鼓楼 + 老毛手抓 | 银川 |
| … | | | | |

**校验项**：
- [ ] 每天是否只有 2–3 个主点
- [ ] 首末两日是否减半
- [ ] 有没有单日车程 > 5 h
- [ ] 有没有把"大门到核心景点"的时间算进去
- [ ] 每个城市都有一句"为什么来"
- [ ] 末班车后是否有过夜方案

这张表确认后，才进入 ③ 核实（去查这些点的票价 / 预约 / 地址）。

# 附：案例演示（青甘蒙环线）

**走廊判定**：大环线 → 主力 = 铁路 + 包车，不是纯高铁。

**城市定位**：
- 呼和浩特 = 召庙群 + 博物院（草原与都市交汇）
- 银川 = 西夏陵 + 贺兰山岩画 + 镇北堡
- 兰州 = 黄河穿城（中山桥 + 水车园）
- 敦煌 = 莫高窟 + 鸣沙山（核心）
- 张掖 = 七彩丹霞

**锚点识别**：
- 9/26 红眼落地（次日凌晨才到）
- 10/2 21:25 接孩子（3U6357）
- 10/3 莫高窟 12:15 固定场次
- 10/7 21:45 返程航班

**编排结果**：
- 敦煌给 3 晚（最重），兰州给 1 晚（中转），张掖 1 晚
- 10/2 接人日 → 只排接机 + 沙洲夜市（轻量）
- 10/3 莫高窟 12:15 是硬锚点 → 上午留白、下午接鸣沙山
- 10/4 西线 + 日落 → 全天户外，标 `全天户外`
- 大环线西段（敦煌→张掖→兰州）走铁路 D 字头，**没有班次的路段用包车**

**排出来的坑（已避开）**：
- 兰州→敦煌跨夜软卧 → 省一晚住宿但要标"次日 06:35 到，当天不能排满"
- 七彩丹霞 18:00 闭园（旺季），看日落要卡时间
- 10/1 国庆当日跨省 → 抢票难度最高，提前 15 天卡点
