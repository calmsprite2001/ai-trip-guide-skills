# 配色方案库 · 4 套

## 用法

整套设计的颜色**只由这 11 个变量驱动**，换配色 = 换 `:root` 里这 11 行，其余 CSS 一行不动。

```css
:root{
  --paper:  ;   /* 页面底色（点阵纸底也用它） */
  --paper2: ;   /* 卡片面 */
  --paper3: ;   /* 次级底：标签、表头、按钮 ghoster */
  --ink:    ;   /* 主文字 + 所有描边（漫画风的黑线） */
  --ink2:   ;   /* 正文次级文字 */
  --ink3:   ;   /* 弱化文字、注释 */
  --red:    ;   /* 重点 / 时间 / 今日高亮 */
  --mustard:;   /* 标签底 / 主按钮 / 印章 */
  --olive:  ;   /* 完成态 / 已出票 */
  --sky:    ;   /* 票务 / 链接 / 候补 */
  --terra:  ;   /* 提醒 / 警示 */
}
```

**切换方式**：多套内置时用 `body.<name>` 覆盖（模板里已有 `setTheme()` 可参考），或直接改 `:root`。

---

## A · 奶油暖调（默认）

纸张 + 漫画分格的暖底，最耐看，适合历史文化线路、西北/中原/丝路。

```css
:root{
  --paper:#F7EEDC; --paper2:#FFFCF4; --paper3:#F2E6CE;
  --ink:#211C15; --ink2:#5B5240; --ink3:#8E846A;
  --red:#C8503A; --mustard:#E5A93C; --olive:#6D8B4B; --sky:#6FA8CF; --terra:#C1764A;
}
```
`theme-color` 用 `#F7EEDC`。配图底色需落在 `#F7EEDC` 同色系（暖沙黄）。

---

## B · 清透冷调

干净的冷白 + 青绿，适合海岛、江南水乡、高原湖泊、夏季线路。

```css
body.cool{
  --paper:#EDF6F6; --paper2:#FFFFFF; --paper3:#E2EFF0;
  --ink:#1D2A33; --ink2:#4A5A64; --ink3:#7C8C95;
  --red:#D2604A; --mustard:#EFC04A; --olive:#74A05A; --sky:#4E9BC4; --terra:#C98A5B;
}
```
`theme-color` 用 `#EDF6F6`。配图底色偏冷白，水体用青蓝。

---

## C · 墨绿山野

淡青绿纸底 + 竹青主色 + 朱砂点缀。适合森林/竹海/山水/山野徒步、日式与东南亚线路。

```css
body.forest{
  --paper:#EDF2E7; --paper2:#FBFDF8; --paper3:#DFE9D6;
  --ink:#1B231B; --ink2:#4B574A; --ink3:#828F80;
  --red:#B4472F; --mustard:#D8A62C; --olive:#4E7C3F; --sky:#4C8A8A; --terra:#9E6B44;
}
```
`theme-color` 用 `#EDF2E7`。配图底色偏苔绿，植被用竹青与墨绿，水体用青碧而非天蓝。

---

## D · 靛青海港

浅靛蓝纸底，比 B 更沉一档、蓝得更明显。适合都市、海港、夜景多、极地/雪山线路。

```css
body.indigo{
  --paper:#E8EFF6; --paper2:#FFFFFF; --paper3:#D8E4EF;
  --ink:#161F2B; --ink2:#41505F; --ink3:#7B8B9A;
  --red:#C24A3C; --mustard:#E3A933; --olive:#5C8B57; --sky:#3F7FB0; --terra:#B0703F;
}
```
`theme-color` 用 `#E8EFF6`。配图底色偏冷灰蓝，天空可加深。

## 选型建议

| 场景 | 首选 |
|---|---|
| 历史/丝路/西北/中原、想有"手账感" | **A 奶油暖调** |
| 海岛、江南、湖泊、夏季、想清爽 | **B 清透冷调** |
| 森林、竹海、山野徒步、日式/东南亚 | **C 墨绿山野** |
| 都市、海港、雪山、夜景 | **D 靛青海港** |

**默认用 A**，除非线路气质明显偏冷/偏绿。桦哥 2026 中秋国庆青甘蒙环线用的是 A。

---

## 语义色约定（别乱用）

| 变量 | 固定语义 |
|---|---|
| `--red` | 重点、时间、今日高亮、警告框描边 |
| `--mustard` | 标签底、主按钮、倒计时印章 |
| `--olive` | 完成态（已出票 / 已预约 / 已核验） |
| `--sky` | 票务、链接、候补状态 |
| `--terra` | 提醒、注意事项（比 red 弱一档） |
| `--ink3` | 注释、来源说明 |

**同一语义不要换色。** 页面里"已出票"永远是 olive，"候补中"永远是 sky，用户扫一眼就能读状态。

---

## 硬约束

1. **图片底色必须与所选 `--paper` 同色系**，否则配图像是"贴"在页面上。选完配色再定配图的色板指令。
2. **`--ink` 必须够深**（明度差 ≥ 70%），它同时承担描边和正文 —— 漫画风全靠这根线撑。
3. **别引入第 12 个颜色**。需要新语义时，优先用现有的 `--terra` / `--ink3`。
4. **红涨绿跌不适用**（旅游攻略不涉及行情）—— 但 `--red` 做重点色、`--olive` 做完成色这条别倒过来。
